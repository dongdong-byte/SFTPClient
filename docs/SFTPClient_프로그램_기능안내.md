# 관측자료 자동 전송 프로그램 기능 안내

## 프로그램 소개

**SFTPClient는 지정된 폴더의 관측자료를 찾아 서버로 보내고, 전송 결과를 관리하는 프로그램입니다.** 정기적인 자료 전송과 특정 기간·관측소의 자료 재전송에 사용할 수 있습니다.

자료를 찾은 뒤 기존 기록과 비교하여 전송할 파일을 선정하고, 서버에 도착한 파일을 확인한 후 결과를 저장합니다. 운영체제의 예약 실행 기능과 연결하면 담당자가 매번 직접 실행하지 않아도 정해진 주기로 작업할 수 있습니다.

## 1. 자료 자동 탐색

- **자료 종류별 설정:** 일별·시간별 자료를 구분하여 원본 폴더와 전송 목적지를 지정할 수 있습니다.
- **날짜별 폴더 확인:** 설정한 날짜 규칙에 따라 자료가 있는 폴더를 찾습니다.
- **하위 폴더 탐색:** 날짜 폴더 아래에 시간별·관측소별 폴더가 여러 단계로 나뉘어 있어도 안쪽 파일을 찾습니다.
- **지연 자료 확인:** 평소에는 최근 자료를 확인하고, 지정한 시각에는 더 넓은 기간을 다시 살펴 늦게 들어온 자료를 찾습니다.

## 2. 전송할 자료 선별

**새로 들어왔거나 변경된 자료, 아직 전송을 마치지 못한 자료를 기록과 대조하여 선별합니다.** 이미 전송을 마친 동일 자료는 반복해서 보내지 않습니다.

파일 크기는 같고 수정 시각만 바뀐 경우에는 저장된 내용 비교 정보와 대조합니다. 내용이 같다고 확인되면 새 수정본으로 취급하지 않습니다. 작성 중인 임시 파일이나 빈 파일, 수정 직후 대기 시간이 필요한 파일은 전송 대상에서 제외합니다.

필요한 자료 종류가 모두 모였을 때 전송을 시작하도록 설정할 수도 있습니다. 예를 들어 함께 필요한 자료 중 일부가 아직 도착하지 않았다면 해당 묶음의 전송을 기다립니다. 이 기능은 선택 사항이며 기본 설정에서는 사용하지 않습니다.

## 3. 서버 전송과 완료 확인

선정한 자료를 지정 서버로 보내고, 받는 쪽에 필요한 폴더가 없으면 생성합니다. 전송 직전에 원본이 존재하는지와 파일 크기가 달라지지 않았는지도 다시 확인합니다.

파일을 보내는 동안에는 임시 이름을 사용합니다. 전송한 파일의 크기를 확인한 뒤 정식 이름으로 바꾸고, 최종 파일까지 확인해야 전송 완료로 기록합니다.

여러 폴더의 전송 작업을 함께 처리할 수 있으며, **동시 작업 수와 한 번에 보낼 파일 수**를 조절할 수 있습니다.

## 4. 자동·수동 재전송과 관측소 선택

- **자동 재전송:** 일반 전송 후 남은 처리 여유로 과거 기간의 미전송·변경 자료를 추가 확인하여 보냅니다.
- **수동 재전송:** 담당자가 시작일·종료일·자료 종류를 지정하여 필요한 범위를 다시 처리할 수 있습니다.
- **관측소 선택:** 수동 재전송 시 관측소 한 곳 또는 여러 곳을 지정할 수 있습니다. 날짜·자료 종류 조건과 함께 사용할 수 있습니다.
- **추가 재시도:** 자동 재시도 횟수를 모두 사용한 자료에도 수동 실행으로 추가 시도 기회를 줄 수 있습니다.

예를 들어 **“두 관측소의 특정 기간 일별 자료 중 아직 보내지 못한 자료”**를 선택하여 처리할 수 있습니다. 재전송은 허용된 기간과 조건 안에서 필요한 자료를 선별하며, 이미 완료된 자료 전체를 강제로 다시 보내는 방식은 아닙니다.

## 5. 장애 대응과 작업 중복 방지

전송 실패 사유와 시도 횟수를 저장하고, 다음 실행에서 범위와 횟수 조건에 맞는 자료를 다시 시도합니다. 프로그램이 중단되었다면 다음 전송 실행에서 진행 중으로 남은 기록과 전송 임시 파일을 정리합니다.

진행 중인 서버 작업에 일정 시간 동안 진전이 없으면 실행을 중단하도록 합니다. 같은 전송 기록을 사용하는 작업의 중복 실행을 제한하며, 수동 재전송은 다른 작업이 끝나기를 정해진 시간까지 기다릴 수 있습니다.

## 6. 자료·전송 기록 관리

프로그램은 자료 관리대장에 다음 정보를 저장하고 다음 실행의 판단에 활용합니다.

- **자료 정보:** 이름, 종류, 크기, 최초 발견 시점, 변경 차수
- **전송 상태:** 대기, 진행 중, 완료, 실패
- **처리 결과:** 시도 횟수, 서버 저장 위치, 완료 확인 시점, 실패 사유

같은 이름의 자료가 변경되면 차수를 올려 이전 자료와 수정본의 전송 결과를 구분합니다. 프로그램 교체 시에는 지원하는 이전 기록 형식을 자동 갱신하여 기존 이력을 유지합니다.

별도로 날짜별 실행 기록을 남겨 처리 건수와 제외 사유 등을 확인할 수 있으며, 보존기간이 지난 실행 기록 파일은 정리합니다.

## 7. 접속 정보 보호와 사전 점검

윈도우의 정보 보호 기능인 **DPAPI**를 사용하여 서버 주소·접속 아이디·포트 번호를 평문 대신 암호화된 값으로 저장하고 사용할 수 있습니다. 서버 접속 시에는 등록된 상대 서버인지 확인합니다.

실행 전에는 설정과 필요한 인증 파일을 검사합니다. 실제 전송 없이 대상 자료를 살펴보는 **미리보기**, 외부 서버 대신 지정한 저장 위치로 복사하는 **시험용 전송**, 최초 설치 시 서버에 이미 있는 자료를 크기로 대조하여 기록에 반영하는 기능도 제공합니다.

## 사용 범위

이 프로그램은 **접근 가능한 원본 폴더의 자료를 지정 서버로 보내는 용도**입니다. 날짜 폴더까지의 위치와 전송 조건은 사전에 설정해야 합니다.

도착 확인은 파일 존재와 크기를 기준으로 하며, 관측값 자체의 품질을 검사하지는 않습니다. 자료 묶음 확인은 전송 시작 조건이며, 일부 전송이 실패했을 때 이미 보낸 파일 전체를 되돌리는 기능은 아닙니다. 과거 파일 내용 전체의 보관·복원, 중단 지점부터 이어 보내기, 다른 서버에서 자료 내려받기는 제공하지 않습니다.
