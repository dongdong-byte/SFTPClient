# 관측자료 자동 전송 프로그램 기능 설명

작성일: 2026년 9월 23일 · 프로그램명: SFTPClient

## 1. 프로그램 개요

**기관에서 생성되는 관측자료를 찾아 지정된 서버로 전송하고, 전송 결과를 기록·관리하는 프로그램입니다.** 담당자가 상시 확인하기 어려운 무인 운영환경을 고려하여, 중복 전송 방지와 누락 자료 재전송, 장애 후 재처리 기능을 함께 구현했습니다.

운영체제의 예약 실행 기능과 연계하여 정기적으로 실행하며, 자료 종류별 원본 위치와 전송 목적지, 확인 기간과 처리량을 설정할 수 있습니다.

**기본 흐름: 자료 찾기 → 기존 기록과 비교 → 전송 대상 선정 → 서버 전송 → 도착 확인 → 결과 저장**

## 2. 구현한 주요 기능

**① 자료 자동 탐색과 기관별 폴더 대응**  
날짜별로 필요한 폴더를 찾아 일별·시간별 자료를 수집합니다. 날짜 폴더 아래에 시간별·관측소별 폴더가 여러 단계로 나뉘어 있어도 안쪽까지 탐색합니다. 최근 자료를 확인하고, 지정한 시각에는 더 넓은 기간을 다시 살펴 늦게 들어온 자료도 찾습니다.

**② 새 자료·수정 자료 선별과 중복 전송 방지**  
자료의 크기·수정 시각과 기존 전송 기록을 비교하여 보낼 대상을 정합니다. 이미 보낸 자료는 반복 전송을 줄이고, 수정된 자료는 다시 처리합니다. 크기는 같고 수정 시각만 바뀐 경우에는 내용을 비교하여 동일하다고 확인되면 불필요한 변경 처리를 하지 않습니다.

**③ 미완성 자료 제외와 자료 묶음 확인**  
작성 중인 임시 파일, 빈 파일, 수정 직후 대기 시간이 필요한 자료는 바로 보내지 않습니다. 필요한 자료 종류가 한 묶음으로 갖춰졌을 때 전송을 시작하는 기능도 선택하여 사용할 수 있습니다. 이 기능은 기본적으로 꺼져 있으며, 전송 중 실패한 묶음 전체를 되돌리는 기능은 아닙니다.

**④ 파일 전송과 도착 확인**  
전송 직전에 원본의 존재와 크기를 다시 확인하고, 받는 쪽에 필요한 폴더가 없으면 생성합니다. 임시 이름으로 전송한 뒤 크기를 확인하고 정식 이름으로 바꿉니다. 최종 파일의 크기까지 확인해야 완료로 기록합니다. 여러 작업을 함께 처리하고 한 번에 보낼 파일 수를 조절할 수 있습니다.

**⑤ 자동·수동 재전송**  
일반 전송 후 남은 처리 여유로 과거 기간의 미전송·변경 자료를 추가 확인합니다. 담당자가 시작일·종료일·자료 종류를 지정하여 재전송할 수도 있습니다. 자동 재시도 횟수를 모두 사용한 자료에도 수동으로 추가 시도 기회를 줄 수 있습니다. 재전송은 허용된 기간과 조건 안에서 필요한 자료를 선별합니다.

**⑥ 특정 관측소 선택**  
수동 재전송 시 관측소 한 곳 또는 여러 곳을 선택할 수 있습니다. 기간과 자료 종류를 함께 지정하여 필요한 자료만 처리하고, 요청한 관측소별 발견 건수도 확인할 수 있습니다.

**⑦ 장애 대응과 중복 실행 방지**  
전송 실패 사유와 시도 횟수를 기록하고 다음 실행에서 조건에 맞는 자료를 다시 시도합니다. 이전 실행이 중단되었으면 진행 중으로 남은 기록과 전송 임시 파일을 정리합니다. 통신에 일정 시간 진전이 없으면 실행을 중단하도록 했으며, 같은 작업이 겹쳐 실행되는 것을 제한합니다.

**⑧ 자료·전송 관리대장**  
자료 이름·종류·크기·최초 발견 시점과 변경 차수를 저장합니다. 전송 결과는 차수별로 대기·진행 중·완료·실패로 구분하고, 시도 횟수·도착 위치·완료 시점·실패 사유를 함께 관리합니다. 같은 이름의 수정본도 이전 전송분과 구분하며, 프로그램 개선 시 지원하는 이전 기록 형식에 필요한 항목을 자동 추가하고 버전을 갱신합니다.

**⑨ 접속 정보 보호**  
윈도우 정보 보호 기능인 **DPAPI**를 사용하여 서버 주소·접속 아이디·포트 번호를 평문 대신 암호화된 값으로 저장하고 사용할 수 있습니다. 접속 시 등록된 상대 서버인지 확인하며, 잘못된 설정과 필요한 인증 파일도 실행 전에 점검합니다.

**⑩ 설치·사전 점검과 실행 기록**  
최초 설치 시 서버에 이미 있는 자료의 크기를 대조해 기존 전송분을 반영할 수 있습니다. 실제로 보내기 전 대상을 확인하는 미리보기와 시험용 파일 복사 기능도 제공합니다. 실행 결과는 날짜별 파일에 보관하고 보존기간이 지난 실행 기록 파일을 정리하며, 처리 건수·제외 사유·실패 결과를 요약합니다.

## 3. 현재 상태와 남은 작업

위 기능은 현재 프로그램에 구현되어 있습니다. **기능 구현 완료와 기관별 실제 운영환경 검증 완료는 구분하며**, 실제 폴더에서의 자료 탐색, 통신 장애 후 재처리, 최신 설정 적용과 처리 시간은 현장에서 확인해야 합니다.

앞으로 진행할 주요 작업은 다음과 같습니다.

- **오래된 전송 이력 자동 정리:** 보존기간이 지난 관리대장 기록을 정리하는 기능입니다. 이미 구현된 실행 기록 파일 정리와는 별개입니다.
- **리눅스 환경 적용·시험:** 실행파일 준비, 자료 경로와 예약 실행 설정, 서버 연결 및 전체 동작 확인이 남아 있습니다.
- **기존 자료를 정해진 폴더로 모으기:** 여러 저장 위치의 자료를 관측 날짜에 맞는 폴더로 복사하고, 기존 전송 기능과 연결할 예정입니다.

다른 서버에서 자료를 내려받는 기능은 후속 단계입니다. 현재의 도착 확인은 파일 존재와 크기를 기준으로 하며, 관측값 자체의 품질 검사나 과거 파일 내용 전체의 보관·복원은 포함하지 않습니다.
